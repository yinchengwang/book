## R-Tree 节点结构

```
┌─────────────────────────────────────────────────────────────────┐
│                      R-Tree 节点结构                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                      内部节点                               │  │
│  │  ┌─────────────────────────────────────────────────────┐ │  │
│  │  │  is_leaf = false                                    │ │  │
│  │  ├─────────────────────────────────────────────────────┤ │  │
│  │  │  n_entries = 3                                      │ │  │
│  │  ├─────────────────────────────────────────────────────┤ │  │
│  │  │  parent = <offset>                                  │ │  │
│  │  ├─────────────────────────────────────────────────────┤ │  │
│  │  │  bbox = {min_x, min_y, max_x, max_y}               │ │  │
│  │  │       (所有子节点的 MBR)                             │ │  │
│  │  ├─────────────────────────────────────────────────────┤ │  │
│  │  │  children[0] = offset to child[0]                  │ │  │
│  │  │  children[1] = offset to child[1]                  │ │  │
│  │  │  children[2] = offset to child[2]                  │ │  │
│  │  │  ...                                                │ │  │

│  └───────────────────────────────────────────────────────────┘  │

│  │                      叶子节点                               │  │
│  │  ┌─────────────────────────────────────────────────────┐ │  │
│  │  │  is_leaf = true                                     │ │  │

│  │  │  bbox = {min_x, min_y, max_x, max_y}               │ │  │
│  │  │       (所有几何对象的 MBR)                          │ │  │
│  │  ├─────────────────────────────────────────────────────┤ │  │
│  │  │  geometries[0] = {type, Point, bbox}              │ │  │

```

## R-Tree 插入流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      R-Tree 插入流程                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         新几何对象 g                             │
│                              │                                   │
│                              ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  从根节点开始   │                          │
│                    │  找到插入位置   │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│         ┌───────────────────────────────────────────────┐       │
│         │           选择子节点 (R-Tree ChooseLeaf)       │       │
│         │                                               │       │
│         │   1. 从根节点开始                            │       │
│         │   2. 如果是内部节点:                         │       │
│         │      选择 MBR 增量最小的子节点               │       │
│         │      (贪心选择: 增加面积最小的)             │       │
│         │   3. 递归直到叶子节点                        │       │
│         │                                               │       │
│         └─────────────────────┬─────────────────────────┘       │
│                               │                                   │
│                               ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  插入到叶子    │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│                    ┌─────────────────┐                          │
│                    │  叶子节点满?    │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│              ┌──────────────┴──────────────┐                     │
│              │                             │                     │
│              ▼                             ▼                     │
│    ┌─────────────────┐           ┌─────────────────┐           │
│    │      否         │           │       是        │           │
│    │   更新 MBR      │           │   节点分裂     │           │
│    │   向上传播     │           │               │           │
│    └────────┬────────┘           └────────┬────────┘           │
│             │                             │                      │
│             │                             ▼                      │
│             │               ┌─────────────────────────┐        │
│             │               │   二次分裂算法          │        │
│             │               │                        │        │
│             │               │ 1. 分离最远的两个条目 │        │
│             │               │ 2. 贪心分配剩余条目   │        │
│             │               │ 3. 更新父节点 MBR     │        │
│             │               └───────────┬───────────┘        │
│             │                           │                      │
│             └───────────────────────────┼──────────────────────┘
│                                         │
│                                         ▼
│                               ┌─────────────────┐
│                               │  调整父节点    │
│                               │  MBR + 递归   │
│                               │  分裂处理      │
│                               └─────────────────┘
```

## R-Tree 范围查询流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      R-Tree 范围查询流程                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         查询矩形 Q                                │
│                              │                                   │
│                              ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  从根节点开始   │                          │
│                    │  递归搜索       │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│         ┌───────────────────────────────────────────────┐       │
│         │              节点查询                           │       │
│         │                                               │       │
│         │   ┌───────────────────────────────────────┐  │       │
│         │   │  if 节点 MBR 与 Q 不相交:              │  │       │
│         │   │      return [] // 剪枝                 │  │       │
│         │   │                                       │  │       │
│         │   │  else if 是叶子节点:                  │  │       │
│         │   │      for each geometry in node:       │  │       │
│         │   │          if geometry.MBR 与 Q 相交:   │  │       │
│         │   │              results.add(geometry)     │  │       │
│         │   │                                       │  │       │
│         │   │  else: // 内部节点                    │  │       │
│         │   │      for each child in node:          │  │       │
│         │   │          search(child, Q)             │  │       │
│         │   └───────────────────────────────────────┘  │       │
│         │                                               │       │
│         └─────────────────────┬─────────────────────────┘       │
│                               │                                   │
│                               ▼                                   │
│                    ┌─────────────────┐                          │
│                    │   返回结果集   │                          │
│                    │                 │                          │
│                    │  精确几何对象   │                          │
│                    │  (需二次判断)  │                          │
│                    └─────────────────┘                          │
```

## R-Tree KNN 查询

```
┌─────────────────────────────────────────────────────────────────┐
│                      R-Tree KNN 查询                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         查询点 P, K=3                            │
│                              │                                   │
│                              ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  初始化优先队列 │                          │
│                    │  (按距离排序)    │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│                    ┌─────────────────┐                          │
│                    │  从根节点开始   │                          │
│                    │  深度优先搜索   │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│         ┌───────────────────────────────────────────────┐       │
│         │              Best-First 搜索                   │       │
│         │                                               │       │
│         │   1. 计算当前节点 MBR 到 P 的最小距离        │       │
│         │      mindist(MBR, P)                          │       │
│         │                                               │       │
│         │   2. 使用 mindist 作为优先级                 │       │
│         │      (mindist 小的先访问)                    │       │
│         │                                               │       │
│         │   3. 优先访问可能包含最近邻的节点           │       │
│         │                                               │       │
│         │   4. 当找到 K 个候选时，可剪枝                │       │
│         │      跳过 mindist > 当前最大距离的节点       │       │
│         │                                               │       │
│         └─────────────────────┬─────────────────────────┘       │
│                               │                                   │
│                               ▼                                   │
│                    ┌─────────────────┐                          │
│                    │   返回 Top-K   │                          │
│                    │   最近邻        │                          │
│                    └─────────────────┘                          │
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                      mindist 计算                          │  │
│  │                                                            │  │
│  │   Point:  mindist = 0 (点在 MBR 内)                       │  │
│  │                                                            │  │
│  │            │                                              │  │
│  │   2D:      │  ┌───────────┐                              │  │
│  │            │  │           │                              │  │
│  │            │  │     P     │                              │  │
│  │            │  │   (0.5,0.5)│                              │  │
│  │            │  │           │                              │  │
│  │            │  └───────────┘                              │  │
│  │            │  (0.3,0.3) ─ (0.7,0.7)                     │  │
│  │            │                                              │  │
│  │            │  mindist = sqrt((0.5-0.7)² + (0.5-0.7)²)   │  │
│  │            │              = 0.283                        │  │
│  │                                                            │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
