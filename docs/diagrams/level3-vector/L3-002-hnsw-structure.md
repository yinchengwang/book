## 搜索流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      HNSW 搜索流程                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         查询向量 q                                │
│                              │                                   │
│                              ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  从顶层开始搜索  │                          │
│                    │    Layer L      │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│         ┌───────────────────────────────────────────────┐       │
│         │           Greedy 搜索当前层                      │       │
│         │                                               │       │
│         │   ef = k × 5 + 50 (推荐值)                     │       │
│         │                                               │       │
│         │   1. 选择entry point                          │       │
│         │   2. 贪心搜索找最近邻                          │       │
│         │   3. 直到没有更近的邻居                        │       │
│         │                                               │       │
│         └─────────────────────┬─────────────────────────┘       │
│                               │                                   │
│                               ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  下降到下一层    │                          │
│                    │   Layer L-1     │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│                    ┌─────────────────┐                          │
│                    │  继续贪心搜索   │                          │
│                    │  (使用上层的    │                          │
│                    │   最近邻作为    │                          │
│                    │   起点)        │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│              ┌──────────────┴──────────────┐                     │
│              │                             │                     │
│              ▼                             ▼                     │
│    ┌─────────────────┐           ┌─────────────────┐           │
│    │  继续下降?       │           │  到达 Layer 0   │           │
│    │  L-1 > 0?      │           │                 │           │
│    └────────┬────────┘           └────────┬────────┘           │
│             │                             │                      │
│             │ Yes                         │ No                  │
│             ▼                             ▼                      │
│    ┌─────────────────┐           ┌─────────────────┐           │
│    │  候选队列传递   │           │  K 近邻列表     │           │
│    │  到下一层       │           │  Top-K 结果     │           │
│    └─────────────────┘           └─────────────────┘           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 构建流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      HNSW 构建流程                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         新向量 v                                 │
│                              │                                   │
│                              ▼                                   │
│                    ┌─────────────────┐                          │
│                    │  确定插入层数   │                          │
│                    │  m_L = -log(rand) * L                     │  │
│                    │  (几何分布)      │                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│                    ┌─────────────────┐                          │
│                    │  初始化 ep     │                          │
│                    │ (如果为空则返回)│                          │
│                    └────────┬────────┘                          │
│                             │                                    │
│                             ▼                                    │
│    ┌───────────────────────────────────────────────┐            │
│    │           自顶向下搜索                           │            │
│    │                                                │            │
│    │   for layer = L to 1:                         │            │
│    │       ep = search_layer(q, ep, ef=1)         │            │
│    │   // 贪心搜索找到当前层的最近邻                 │            │
│    └─────────────────────┬─────────────────────────┘            │
│                          │                                        │
│                          ▼                                        │
│    ┌───────────────────────────────────────────────┐            │
│    │           自底向上插入                          │            │
│    │                                                │            │
│    │   for layer = 1 to L:                         │            │
│    │       // 选取 M 个最近邻作为邻居                │            │
│    │       neighbors = search_layer(q, ep, ef=M)   │            │
│    │       // 连接双向边                            │            │
│    │       connect(v, neighbors)                   │            │
│    │       ep = v // 更新 entry point              │            │
│    └─────────────────────┬─────────────────────────┘            │
│                          │                                        │
│                          ▼                                        │
│                    ┌─────────────────┐                          │
│                    │    维护连接数   │                           │
│                    │                  │                           │
│                    │ M 个固定邻居:   │                           │
│                    │ - 如果超过 M,   │                           │
│                    │   删除最远的    │                           │
│                    │ - 更新 MBR      │                           │
│                    └─────────────────┘                          │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
