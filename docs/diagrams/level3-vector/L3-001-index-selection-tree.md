## HNSW 参数调优

```
┌─────────────────────────────────────────────────────────────────┐
│                      HNSW 参数调优指南                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │                    核心参数                              │    │
│  │                                                          │    │
│  │   M (层间连接数)                                          │    │
│  │   ├── 推荐值: 8-48 (默认 16)                            │    │
│  │   ├── M ↑ → 召回率 ↑, 内存 ↑, 构建时间 ↑              │    │
│  │   └── 场景: 召回优先 → M=32-48; 内存优先 → M=8-16    │    │
│  │                                                          │    │
│  │   efConstruction (构建时搜索范围)                         │    │
│  │   ├── 推荐值: 100-500 (默认 200)                        │    │
│  │   ├── efConstruction ↑ → 召回率 ↑, 构建时间 ↑         │    │
│  │   └── 场景: 高召回需求 → efConstruction=400-500        │    │
│  │                                                          │    │
│  │   efSearch (查询时搜索范围)                               │    │
│  │   ├── 推荐值: 50-1000 (默认 100)                        │    │
│  │   ├── efSearch ↑ → 召回率 ↑, 查询时间 ↑                │    │
│  │   └── 场景: efSearch ≈ top_k × 5 + 50                  │    │
│  │                                                          │    │
│  └─────────────────────────────────────────────────────────┘    │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │                    调优建议                              │    │
│  │                                                          │    │
│  │   100K 数据集:                                            │    │
│  │   ├── M = 16, efConstruction = 200, efSearch = 100     │    │
│  │   └── 预期: Recall@10 > 95%, 构建 < 1min               │    │
│  │                                                          │    │
│  │   1M 数据集:                                             │    │
│  │   ├── M = 24, efConstruction = 300, efSearch = 200    │    │
│  │   └── 预期: Recall@10 > 95%, 构建 < 10min              │    │

│  │                                                          │    │
```
