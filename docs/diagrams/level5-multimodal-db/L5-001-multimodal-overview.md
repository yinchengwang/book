## 七种存储引擎

| 引擎 | 数据模型 | 索引类型 | 核心 API | 适用场景 |
|------|----------|----------|----------|----------|
| KV Engine | 键值 | BTree, Hash | get/set/del | 缓存, 会话 |
| Vector Engine | 向量 | HNSW, IVF-PQ, NSW | insert/search | 相似度检索 |
| Graph Engine | 图 | 邻接表, CSR | vadd/ead/del | 社交网络, 知识图谱 |
| Doc Engine | 文档 | 倒排索引, BM25 | insert/search | 全文检索 |
| Spatial Engine | 空间 | R-Tree, Quadtree | insert/search | GIS, LBS |
| TS Engine | 时序 | TSM, Tag Index | insert/query/agg | IoT, 监控 |
| CF Engine | 列族 | 列压缩 | insert/query | 日志, 指标 |

└──────┬───────┘
       │
       ├──► KV 查询 ──────► BTree 索引 ──────► Buffer Pool

       │
       ├──► 图查询 ───────► Cypher ─────────► 图算法
       │

       ├──► 空间查询 ─────► R-Tree ─────────► 空间谓词
