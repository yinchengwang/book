## RRF 融合算法

```
┌─────────────────────────────────────────────────────────────────┐
│                      RRF 融合算法                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                      算法定义                              │  │
│  │                                                            │  │
│  │              RRF_score(d) = Σ 1/(k + rank_i(d))          │  │
│  │                                                            │  │
│  │  其中:                                                    │  │
│  │    • d: 文档                                              │  │
│  │    • k: 常数 (通常 k=60)                                  │  │
│  │    • rank_i(d): 文档 d 在第 i 个检索结果中的排名          │  │
│  │                                                            │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                      示例计算                              │  │
│  │                                                            │  │
│  │  向量检索结果:  Doc_A(rank=1), Doc_B(rank=2),           │  │
│  │                 Doc_C(rank=3)                             │  │
│  │                                                            │  │
│  │  BM25 结果:       Doc_B(rank=1), Doc_A(rank=2),         │  │
│  │                 Doc_D(rank=3)                             │  │
│  │                                                            │  │
│  │  ─────────────────────────────────────────────────────    │  │
│  │                                                            │  │
│  │  RRF(doc_A) = 1/(60+1) + 1/(60+2) = 0.0164 + 0.0161   │  │
│  │            = 0.0325                                       │  │
│  │                                                            │  │
│  │  RRF(doc_B) = 1/(60+2) + 1/(60+1) = 0.0161 + 0.0164    │  │
│  │            = 0.0325                                       │  │
│  │                                                            │  │
│  │  RRF(doc_C) = 1/(60+3) + 0 = 0.0159                     │  │
│  │                                                            │  │
│  │  RRF(doc_D) = 0 + 1/(60+3) = 0.0159                     │  │
│  │                                                            │  │
│  │  ─────────────────────────────────────────────────────    │  │
│  │                                                            │  │
│  │  最终排序: Doc_A ≈ Doc_B > Doc_C = Doc_D                │  │
│  │                                                            │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                      k 值影响                              │  │
│  │                                                            │  │
│  │   k 越小 → 更重视排名靠前的结果                           │  │
│  │   k 越大 → 各路检索结果更平等加权                         │  │
│  │                                                            │  │
│  │   k=0:   纯排名, rank=1 永远排第一                        │  │
│  │   k=60:  推荐默认值, 平衡权重                             │  │
│  │   k=100: 更平均, 减少头部优势                              │  │
│  │                                                            │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## RAG 生成流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      RAG 生成流程                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         Top-K 文档                               │
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────────┐│
│  │                      上下文构建                              ││
│  │                                                             ││
│  │  ┌─────────────────────────────────────────────────────┐   ││
│  │  │                  文档处理                            │   ││
│  │  │                                                     │   ││
│  │  │   for doc in Top-K:                                │   ││
│  │  │       if doc.length > MAX_CHUNK:                   │   ││
│  │  │           split(doc) // 按段落/句子切分            │   ││
│  │  │       else:                                         │   ││
│  │  │           keep(doc)                                 │   ││
│  │  │       enrich(doc) // 添加元信息                      │   ││
│  │  └─────────────────────────────────────────────────────┘   ││
│  │                                                             ││
│  │  ┌─────────────────────────────────────────────────────┐   ││
│  │  │                  上下文组装                          │   ││
│  │  │                                                     │   ││
│  │  │   context = ""                                     │   ││
│  │  │   for doc in sorted_docs_by_relevance:             │   ││
│  │  │       if len(context) + len(doc) < MAX_CONTEXT:    │   ││
│  │  │           context += f"[{idx}] {doc.content}\n"    │   ││
│  │  │       else:                                         │   ││
│  │  │           break                                     │   ││
│  │  └─────────────────────────────────────────────────────┘   ││
│  └─────────────────────────────────────────────────────────────┘│
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────────┐│
│  │                      Prompt 组装                            ││
│  │                                                             ││
│  │  ┌─────────────────────────────────────────────────────┐   ││
│  │  │   System Prompt:                                    │   ││
│  │  │   "你是一个知识库问答助手..."                        │   ││
│  │  └─────────────────────────────────────────────────────┘   ││
│  │                           │                                ││
│  │                           ▼                                ││
│  │  ┌─────────────────────────────────────────────────────┐   ││
│  │  │   Context:                                         │   ││
│  │  │   """                                              │   ││
│  │  │   [1] xxx...                                      │   ││
│  │  │   [2] xxx...                                      │   ││
│  │  │   [3] xxx...                                      │   ││
│  │  │   """                                              │   ││
│  │  └─────────────────────────────────────────────────────┘   ││
│  │                           │                                ││
│  │                           ▼                                ││
│  │  ┌─────────────────────────────────────────────────────┐   ││
│  │  │   User Query:                                      │   ││
│  │  │   "基于以上上下文, 回答: {question}"               │   ││
│  │  └─────────────────────────────────────────────────────┘   ││
│  └─────────────────────────────────────────────────────────────┘│
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────────┐│
│  │                      LLM 生成                               ││
│  │                                                             ││
│  │   支持模型:                                                ││
│  │   • OpenAI GPT-4/3.5                                      ││
│  │   • Claude 3                                              ││
│  │   • 本地 LLM (Llama, ChatGLM)                            ││
│  │                                                             ││
│  │   参数配置:                                                ││
│  │   • temperature: 0.7 (控制创造性)                         ││
│  │   • max_tokens: 2000                                      ││
│  │   • top_p: 0.9                                           ││
│  └─────────────────────────────────────────────────────────────┘│
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────────┐│
│  │                      后处理                                ││
│  │                                                             ││
│  │   • 引用标注: 在回答中添加来源标记 [1], [2]...            ││
│  │   • 格式优化: Markdown 格式化                              ││
│  │   • 安全检查: 过滤敏感信息                                 ││
│  │   • 质量评估: 检查回答是否基于上下文                        ││
│  └─────────────────────────────────────────────────────────────┘│
│                              │                                   │
│                              ▼                                   │
│                         最终回答                                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
