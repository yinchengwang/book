## Volcano 迭代器模型

```
┌─────────────────────────────────────────────────────────────────┐
│                    Volcano 迭代器模型                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                     Volcano 接口                          │  │
│  │                                                          │  │
│  │   typedef struct PlanState {                            │  │
│  │       Plan *plan;              // 物理计划节点          │  │
│  │       struct PlanState *outer; // 子节点状态            │  │
│  │       struct PlanState *inner; // 子节点状态            │  │
│  │                                                          │  │
│  │       // 核心方法                                        │  │
│  │       TupleTableSlot* (*ExecProcNode)(struct PlanState*);│  │
│  │       void (*ExecInit)(...);                            │  │
│  │       void (*ExecEnd)(...);                             │  │
│  │   } PlanState;                                          │  │
│  │                                                          │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                        执行流程                            │  │
│  │                                                          │  │
│  │   ┌─────────────────────────────────────────────────────┐│  │
│  │   │  // 根节点驱动                                     ││  │
│  │   │  while ((slot = root->ExecProcNode(root)) != NULL) ││  │
│  │   │      process(slot);                                ││  │
│  │   └─────────────────────────────────────────────────────┘│  │
│  │                                                          │  │
│  │   ┌─────────────────────────────────────────────────────┐│  │
│  │   │  // HashJoin 节点执行逻辑                          ││  │
│  │   │  TupleTableSlot* ExecHashJoin(HashJoinState *node) ││  │
│  │   │  {                                                 ││  │
│  │   │      // 先构建 Hash 表                             ││  │
│  │   │      if (!node->hashtable_built)                  ││  │
│  │   │          buildHashtable(node);                    ││  │
│  │   │                                                      ││  │
│  │   │      // 探测阶段                                   ││  │
│  │   │      while ((outer = ExecProcNode(node->outer)))  ││  │
│  │   │      {                                             ││  │
│  │   │          hash = hashJoinKey(outer);               ││  │
│  │   │          inner = hashtable_lookup(node->ht, hash); ││  │
│  │   │          if (inner) return combine(outer, inner); ││  │
│  │   │      }                                             ││  │
│  │   │      return NULL; // 结束                         ││  │
│  │   │  }                                                 ││  │
│  │   └─────────────────────────────────────────────────────┘│  │
│  │                                                          │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
