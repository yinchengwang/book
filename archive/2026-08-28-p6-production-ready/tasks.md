# P6-Final 集成验证任务列表

## 阶段概览

P6-Final 是生产就绪路线图的收尾阶段，目标是完成全量基准测试、压力测试和文档编写。

## 任务分解

### Task #77：全量阶梯基准测试（1K/10K/100K/1M）
- **状态**：completed
- **优先级**：P0
- **预估工时**：2h
- **描述**：执行完整的阶梯基准测试，收集 insert speed、search qps、Recall@10、P50/P99 延迟数据
- **验收标准**：
  - 1K/10K/100K/1M 四档全部通过
  - Recall@10 ≥ 0.95（100K）/ ≥ 0.85（1M）
  - 结果输出到控制台和 JSON 文件

### Task #78：压力测试（并发插入/查询/读写混合）
- **状态**：completed
- **优先级**：P0
- **预估工时**：2h
- **描述**：执行多线程并发压力测试，验证系统稳定性
- **验收标准**：
  - 并发插入/查询无崩溃
  - 读写混合场景无数据损坏
  - 性能衰减在可接受范围内

### Task #79：编写 P6-Final 性能报告
- **状态**：completed
- **优先级**：P1
- **预估工时**：3h
- **描述**：整合全量基准测试和压力测试数据，生成性能报告
- **验收标准**：
  - 报告文件存在且内容完整
  - 包含环境信息、阶梯结果、压力测试结果
  - 包含结论与建议

## 依赖关系

```
Task #77 (全量基准) ──→ Task #79 (性能报告)
Task #78 (压力测试) ──→ Task #79 (性能报告)
```

## 资源需求

### 测试环境
- 内存：≥ 4GB（1M 测试），推荐 8GB
- CPU：多核（压力测试需要）
- 磁盘：≥ 1GB 可用空间

### 测试数据
- 1K 测试：~1MB
- 10K 测试：~10MB
- 100K 测试：~100MB
- 1M 测试：~1GB

## 风险与缓解

### 风险 1：10M 测试内存不足
- **缓解**：使用 GTEST_SKIP 跳过，仅测试 1K-1M

### 风险 2：压力测试超时
- **缓解**：控制测试时长在 5-10 分钟内

### 风险 3：文档工作量大
- **缓解**：优先编写核心 API 文档，其他文档后续补充
