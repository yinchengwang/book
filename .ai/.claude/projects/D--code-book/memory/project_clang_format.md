用户希望基于 clang 为该 C/C++ 项目生成编码风格（.clang-format 文件）。

**Why:** 统一代码风格，利用 clang-format 自动格式化 C/C++ 代码。

**How to apply:** 当用户提及编码风格、代码格式化、clang-format 时，应参考此偏好。需要在项目根目录创建或修改 .clang-format 文件。
