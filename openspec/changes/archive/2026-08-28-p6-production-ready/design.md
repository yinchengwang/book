# P6-Final 生产就绪 设计

## 架构概览

P6-Final 是 P5 性能规模化归档后的收尾阶段，专注于全量验证与文档化，
不引入新的运行时架构改动。

```
全量阶梯基准 (Task #77)
  ├─ 1K/10K/100K/1M 四档
  ├─ 收集 insert speed, search qps, Recall@10, P50/P99
  └─ 输出到控制台和 JSON
        ↓
压力测试 (Task #78)
  ├─ 多线程并发插入/查询/读写混合
  └─ 验证无崩溃 + 无数据损坏
        ↓
性能报告 (Task #79)
  ├─ 环境信息
  ├─ 阶梯结果
  ├─ 压力结果
  └─ 结论与建议
```

## 关键测试设计

### 阶梯基准

四档数据集规模，每档独立测试：
- 1K（baseline 验证）
- 10K（常规规模）
- 100K（Recall ≥ 0.95 目标）
- 1M（Recall ≥ 0.85 + 2000 qps 目标）

每档测量：
- insert vectors/s
- search qps（p50/p99 延迟）
- Recall@10（vs 真实 GT）

### 压力测试

- 并发插入：8 线程 × 1000 ops
- 并发查询：10 线程 × 50 queries（**已知 limitation：偶发挂起**）
- 读写混合：8 线程 × 20 ops（半读半写）

### 性能报告

Markdown 格式，包含：
1. 测试环境（CPU、内存、编译器版本）
2. 阶梯基准结果表
3. 压力测试结果
4. 结论与后续优化建议
